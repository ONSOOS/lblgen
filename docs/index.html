ラベルジェネレータ

枠で囲んだ数字・文字の画像をまとめて作成
1行に1つ（1行だけなら読点・カンマ区切りも可）。
文字の高さは数字「0」の高さで、枠の短辺に対する割合です。最大幅を超える文字は「縮小の下限」まで全体を縮め、残りは横だけ縮めます。
形を変えると、文字の高さ・最大幅・上下の位置をその形のおすすめ値にします。
線の太さ・余白・丸みは画像の短辺に対する割合です。
組み合わせの例：
ファイル名には {text}（文字）、{index}（通し番号）、{index:03} のように桁を付けた番号が使えます。
処理はすべてブラウザの中で行い、画像やファイルはどこにも送信しません。 ・ Windows アプリ版 ・ © 2026 OnsooSystem Corp.

使い方

1. 内容

「数字の範囲」では開始・終了・間隔・桁数を決めます。桁のそろえ方は「0で埋める」（07）、「右寄せ」（ゼロサプレス：十の位を空けて一の位の位置に 7。7 と 17 の一の位がそろう）、「中央寄せ」（そろえない：7 も 17 もそれぞれ中央）から選べます。前後に文字（No.、番など）も付けられます。
「文字リスト」では 1行に1つずつ好きな文字を入れます。「CSVを読み込む」で CSV ファイル（UTF-8 / Excel の Shift_JIS）から読み込めます。列が複数あるときは、使う列と見出しの有無を選びます。

2. 文字

フォントは一覧から選びます。Chrome・Edge では「PCのフォントを読み込む」でパソコンに入っているフォントをすべて選べます。フォントファイル（.ttf / .otf）を読み込むこともできます。
文字の高さは数字「0」の高さが基準です。長い文字は最大幅に収まるよう自動で縮めます。
「日本語を含む文字は日本語フォントで描く」をオンにすると、かな・漢字・全角文字・丸数字などを含むラベルだけ、日本語フォント（自動では游ゴシックなど）で描きます。

3. 枠

なし（文字だけ）・円・楕円・正方形・長方形・角丸・多角形・星・ハートなどから選びます。枠線を外すと、内側の塗りだけになります。
「画像から形を登録」で好きな形を追加できます。透過PNGなら不透明な部分、それ以外の画像は暗い部分が形になります。登録した形はこのブラウザに保存されます。

4. 色

文字・枠線・枠の内側・枠の外側の色を選びます。内側と外側はそれぞれ透過にできます（PNG・WEBP・SVG・PowerPoint）。

5. 出力

「まとめてダウンロード」で全部を ZIP にまとめて保存します。PowerPoint は全部を1つのファイルにまとめます。
サムネイルを押すと大きく表示し、「表示中の1つを保存」でその1つだけを保存します。

  • PNG・JPEG には解像度（dpi）を記録します。印刷サイズは 幅px ÷ dpi インチです。
  • SVG と PowerPoint は文字がテキストのまま入るので、あとから編集できます。PowerPoint の図形は Word・Excel に貼っても編集できます。
  • SVG・PowerPoint を開く PC に同じフォントが無いと、別のフォントで表示されます。

設定の保存

設定はこのブラウザに自動で保存され、次に開いたときも同じ状態から始まります。

枠で囲んだ数字・文字のラベル画像を一括作成
数字の連番・文字リスト・CSV から、円・角丸・多角形・登録した形などの枠付きラベルをまとめて作成。PNG・JPEG・WEBP のほか、文字を編集できる SVG・PowerPoint で保存できます。処理はすべてブラウザの中で行い、画像やファイルはどこにも送信しません。

オフラインでも使える Windows アプリ版（TIFF・BMP・PDF にも対応）は GitHub の配布ページ から入手できます。ソースコード：ONSOOS/lblgen

使用ライブラリ：JSZip（MIT / GPLv3）、PptxGenJS（MIT）
作成した画像の利用条件は、使用したフォントのライセンスに従ってください。
